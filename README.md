# Rezka TV

Лёгкий неофициальный клиент для Android TV (Android 7.0+), около 1 МБ.

**Установка:** скачайте APK из раздела [Releases](../../releases) и установите на ТВ (через «Файлы», Downloader или Send Files to TV, разрешив установку из неизвестных источников). При первом запуске укажите адрес источника и свой аккаунт.

Новые версии приложение предлагает само: Настройки → «Доступна версия…».

`config.json` — служебный файл приложения (ссылка поддержки и номер последней версии).
